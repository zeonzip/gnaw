## 🦫 Gnaw 🪵
> The build toolchain for those who want to go **rusty**.

### About Gnaw:
- Gnaw is a full build toolchain built in rust for performance and versatility.
- It allows you to define tasks in a simple and stable manner in rust reeking the benefits of the full rust ecosystem for your tasks.

### Why Gnaw?
- People who want to replace their unnecessarily complex xbuild workflows with a modern and simple task structure.
- Gnaw is perfect for those making projects which has a complex and involved build system which uses legacy build tools like CMake, which miss out on modern programmatic idioms.
- Gnaw is also perfect for the people who want a full rust toolchain across their project while also using the huge rust ecosystem for their tools.
